# Project Structure

```text
smart-retail-ml/
|-- data/
|   |-- raw/dataset.xlsx
|   |-- processed/
|   |-- features/
|   `-- predictions/
|-- models/
|   |-- final_demand_forecasting_pipeline.joblib
|   `-- final_model_metadata.json
|-- reports/
|   |-- eda/
|   |-- model evaluation CSV files
|   `-- final_project_documentation/
|-- src/
|   |-- data/
|   |-- analysis/
|   |-- features/
|   |-- forecasting/
|   `-- backend/
|       |-- app.py, config.py
|       |-- services/
|       |-- utils/
|       |-- templates/
|       `-- static/
|-- tests/test_backend.py
|-- requirements.txt
|-- README.md
`-- .gitignore
```

`data/raw` is the untouched source. `data/processed` contains audit outputs.
`data/features` contains product-calendar and engineered modeling datasets.
`models` contains serialized pipelines and metadata. `src` contains reusable
Python modules. The backend templates and static assets implement the dashboard.

The virtual environment, Python caches, and generated bytecode are intentionally
omitted from this documentation tree.
